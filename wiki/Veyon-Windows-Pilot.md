# Veyon Windows endpoint pilot

The complete procedure, build boundary, one-computer deployment gate, live
acceptance checklist and rollback requirements are maintained in
[Veyon Windows endpoint pilot](https://github.com/wagnerks1990/RoomGoblin/blob/main/docs/VEYON-WINDOWS-PILOT.md).

The Linux pilot does not prove Windows CMD/PowerShell launch or Windows Firewall
enforcement. Those capabilities remain experimental until a complete matching
Veyon 4.11.2 Windows installer is built with the reviewed MinGW/Qt toolchain and
accepted on one disposable endpoint. Individual plugin DLL deployment is never
supported.
