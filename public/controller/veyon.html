Free features and experimental tools

Commands use the current selection, including hidden selections. Clipboard and input tools require the RoomGoblin native bridge.

Additional power options

Shutdown options cannot be cancelled through Veyon. Save student work first. An accepted command is not proof that Windows shut down.

Experimental network access

Windows pilot only. Blocks common web, DNS, encrypted-DNS and proxy ports—not every possible tunnel—and also affects matching services on the local network. The endpoint plugin attempts automatic release after 15 minutes, but a service or machine crash can leave its named firewall rules behind.

Lesson actions and student demonstrations

Select the source and audience before starting a student demonstration. To stop it, select the source and all recipients, including offline participants needing recovery.

Experimental screen recording

Record 1–4 selected screens as a silent WebM contact sheet, up to five minutes or 32 MiB. Captures are sampled about once per second. Keep this workspace visible; hiding it stops recording. Download the result before leaving.
