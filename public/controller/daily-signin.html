A group shares one code. Anyone who knows it can use its enrolled computers. Removing an enrollment file does not revoke a computer that already has it.

Create a group

The timezone cannot be changed after enrollment. Create a new group and reenroll computers to change it.

Enroll a selected computer

Use the exact Windows computer name and its existing local account name. Each file is restricted to that computer and expires for installation after 24 hours.

Use at least 16 characters. Enter this passphrase at the PC during installation. RoomGoblin does not save it.

  1. Download the Windows x64 sign-in package from this RoomGoblin release and extract it.
  2. Sign the esports account out, then sign in with a separate local administrator account.
  3. Open an elevated terminal in the extracted folder. Run .\RoomGoblinSignIn.exe install "C:\path\enrollment.json" and enter the passphrase privately.
  4. Keep administrator recovery available while testing today's code, restart, lock/unlock and offline access.

To remove the requirement, sign in as the administrator and run & "C:\Program Files\RoomGoblin\SignIn\RoomGoblinSignIn.exe" recover in an elevated PowerShell window. It sets a new manual Windows password and keeps automatic sign-in disabled.

Downloading a file does not install the feature. Installation is local and explicit. An offline computer cannot receive immediate code revocations or group changes.
