Upstream: https://github.com/mrdoob/three.js/tree/r187

RoomGoblin modifies the bundled Three.js internal generateUUID entropy source
at build time to use Web Crypto getRandomValues with four unsigned 32-bit words.
Upstream UUID formatting, version and variant bits remain unchanged. There is
no Math.random fallback; unavailable Web Crypto leaves the optional renderer
unavailable and the existing chess interface falls back to 2D. The reproducible
patch is in tools/build-chess-cinematic.cjs; upstream dependency files and the
complete MIT license remain unchanged.

The board, horse/fortress forms, armor, clothing, accessories and cinematic
choreography were created for RoomGoblin. Carved human faces use a head/neck-only
derivative of the explicitly CC0 MakeHuman hm08 basemesh; see assets/MAKEHUMAN-NOTICE.txt
and assets/MAKEHUMAN-CC0.txt for exact source, hash, authors and modifications.
No downloaded textures, fonts, movie artwork, movie character models, music or
proprietary Wizarding World assets are included.

This optional visual renderer does not determine move legality or game outcomes.
